## 📦 Local Development

Clone the repository and install the dependencies:

```bash
git clone https://github.com/akbengaltiger/adarshinfo-portfolio.git
cd adarshinfo-portfolio
npm install
npm run dev
```

Then open `http://localhost:3000`.
